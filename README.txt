# Student Course Registration System

Front-end prototype built with 7 HTML pages and one shared CSS file.

## Files
- index.html — Login
- register.html — Student registration
- dashboard.html — Student dashboard
- courses.html — Course catalog
- course-details.html — Course details and registration request
- schedule.html — Weekly schedule
- admin.html — Admin dashboard
- style.css — Shared styles for all pages

## Run
Open `index.html` in a browser, or open the folder in VS Code and use Live Server.

## Note
This project uses HTML and CSS only. Forms, search, registration, approval, and admin actions are visual prototypes; real authentication, data storage, and registration logic require JavaScript and a back-end/database.
