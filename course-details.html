COMPUTER SCIENCE

Data Structures

CS201 · A core computer science course that introduces fundamental data organization techniques and problem-solving algorithms.

Course Description

What you will learn

This course covers arrays, linked lists, stacks, queues, trees, and searching and sorting algorithms. Students will learn how to select appropriate data structures and analyze their efficiency.

Learning Outcomes

By the end of this course, students should be able to:

  • Explain common data structures and their operations.
  • Implement linear data structures.
  • Compare algorithm time complexities.
  • Select suitable structures for programming problems.
